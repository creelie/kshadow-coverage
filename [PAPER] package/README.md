# v1.6.0 paper package

**Redundant ECoG Coverage on Folded Surfaces: Design Bounds and Certified Mesh Coverage**

Aditi Bose, Deep Bhattacharjee and Ushashi Bhattacharya.

`CertifiedRedundantECoGCoverage.pdf` is the 19-page amsart manuscript.
The complete editable source is in `paper/ecog/` in this release.
The standalone TeX ZIP is attached to the GitHub release after the new
Zenodo DOI has been confirmed; it uses the same manuscript sources.

The new whole-face theorem and certified path bounds establish sufficient
continuous coverage on the represented mesh. They do not establish a
minimum contact count, anatomical fidelity or clinical outcome. The earlier
Lean formalization has a separate scope; the new analytic theorem is not
Lean-formalized. See the release notes and provenance statement.

The manuscript revision is prepared for author review and journal selection.
No journal submission or coauthor approval of this revision is asserted.
